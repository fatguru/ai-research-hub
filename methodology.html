Methodology: LLM Security Assessment Framework

Our assessment framework evaluates production LLM deployments across three dimensions: input handling, tool security, and output filtering.

We tested 847 deployments using automated probes that exercise each LLM's tool-calling capabilities under controlled conditions.

Assessment Dimensions

1. Input Handling

We evaluate how LLMs process and sanitize user inputs before passing them to connected tools and APIs.

2. Tool Security

Analysis of tool invocation patterns, URL validation, and egress control mechanisms across browsing, code execution, and API integration tools.

3. Output Filtering

Evaluation of post-processing filters that prevent sensitive data from being included in LLM responses to users.
